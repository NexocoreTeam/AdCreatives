# Avatars folder

This is where your canonical SecondKind Bold AI avatar lives.

**You set up the avatar ONCE before producing any AI UGC video.**

We use **Higgsfield Soul ID**, Higgsfield's reusable AI-character feature. The Soul ID maintains the avatar's face, hair, outfit, and lighting tone automatically across every generation.

See `recipes/ai-ugc-influencer.md` → "Avatar generation (one-time setup)" for the exact Higgsfield Soul ID prompt and steps.

After setup, save the reference image here as `sk-bold-canonical-avatar.png`.

From then on, every AI UGC video you produce uses this same Soul ID, that's what creates brand recall across episodes (same face, different pains).
