## What these are

1-2 line identity flexes (or POV opens) over a candid clip of a real person in a mundane moment. 5-15 seconds. The line never makes a product or health claim; the person is simply thriving, and the in-group reads between the lines. This is the **messaging test bed**: ship cheap, read response, graduate winners into love letters, creator briefs, and paid hook iterations (keep the line, swap the face and background).

**The harvest rule:** before writing new lines, borrow caption formats live in the operator's own feed THIS week. The bank below uses durable constructions; refresh the wrappers per harvest.

**Compliance note (Layer 0):** the reference example construction "Healed so hard..." should not be used verbatim by a supplement advertiser ("healed" is FDA-prohibited claim language; harmless for a generic creator, risky next to our product). Equivalent constructions that carry the same energy: "Growth." / "Plot twist:" / "Character development:" / "New era:".

### Spicy tier (pride frame; run the six-question gate + operator sign-off before shipping)
